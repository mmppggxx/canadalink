## 🚀 How to Run Locally

1. Download or clone the repository.
2. Open `index.html` in your browser directly.

## 🛠 Optional (Run with Live Server)

If you use VSCode:
- Install the **Live Server** extension.
- Right-click on `index.html` → "Open with Live Server".

Or use CLI:

```bash
npx live-server
```
